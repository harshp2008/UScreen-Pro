## Three ways to use the tablet

<CardGrid stagger>
  <Card title="Extended Display" icon="laptop">
    A real second monitor. A virtual display is created, encoded and streamed to the tablet; touch and pen come back.
  </Card>
  <Card title="Touchpad" icon="pointer">
    Fingers move the pointer like a laptop touchpad: tap to click, two fingers to scroll, three for workspace gestures.
  </Card>
  <Card title="Stylus" icon="pencil">
    A pen tablet with pressure and tilt, a Dynamic style that switches per app, and a long-press pen menu.
  </Card>
  <Card title="Honest by design" icon="approve-check">
    Every page names its sources and says what was run. Only Ubuntu 24.04 with GNOME 46 on Wayland has been run so far.
  </Card>
</CardGrid>
