# Files without a header comment

| File(s) | What it is | Why there is no comment |
|---|---|---|
| `uscreen-pro-gui/package.json`, `uscreen-pro-gui/package-lock.json` | npm manifest and its lock file; the manifest names the app, its scripts and dependencies | JSON has no comments |
| `uscreen-pro-gui/components.json` | shadcn/ui settings (style, aliases, Tailwind paths) read by the shadcn tool | JSON has no comments |
| `uscreen-pro-gui/tsconfig.json`, `uscreen-pro-gui/tsconfig.node.json` | TypeScript settings of the app and of the Vite config | JSON; kept free of comments so every tool that reads them works |
| `uscreen-pro-gui/src-tauri/tauri.conf.json` | Tauri app settings: window, bundle, build commands | JSON has no comments |
| `uscreen-pro-gui/src-tauri/capabilities/default.json` | Tauri permissions of the main window | JSON has no comments |
| `extensions/uscreen-app-lock/metadata.json` | GNOME Shell extension manifest: name, uuid, supported Shell versions | JSON; GNOME Shell reads it strictly |
| `Cargo.lock` (one for the whole workspace) | Cargo's resolved dependency versions | generated by Cargo |
| `LICENSE` | the project's licence text | legal text; not edited |
| `android/gradlew`, `android/gradlew.bat`, `android/gradle/wrapper/gradle-wrapper.properties`, `android/gradle/wrapper/gradle-wrapper.jar` | Gradle wrapper | generated by Gradle; replaced when the wrapper is upgraded |
| `scripts/tests/fixtures/os-release.*` | sample `/etc/os-release` files of the distributions the installer is tested against (arch, bazzite, debian-12, endeavouros, fedora-41, linuxmint, manjaro, nixos, nobara, opensuse-leap, opensuse-tumbleweed, pop, rocky, ubuntu-22.04, ubuntu-24.04) and an empty one | data files copied from real systems; the empty one must stay empty. `scripts/tests/run.sh` documents how they are used |
| `packaging/deb/control` | Debian package control file | the file format of `dpkg-deb`; comments are not portable here |
| `.github/PULL_REQUEST_TEMPLATE.md` | pre-filled text of a new pull request | a comment would be copied into every pull request |
| `docs/llms.txt` | plain-text summary of the project for language-model crawlers | the format is defined by its convention |
| `docs/.nojekyll` | empty marker that turns off Jekyll on GitHub Pages | empty by design |
| `packaging/icons/*.rgba`, `docs/assets/social-preview.png`, `uscreen-pro-gui/src-tauri/icons/*`, `uscreen-pro-gui/src-tauri/icons-src/uscreen-pro.png` | raster images and icon bundles | binary files; each has an SVG source or is described in `docs/assets/README.md` |
| `experiments_and_findings/**` | records and evidence of past experiments | historical; converted to the site format in the documentation site (phase 8) and not edited in place |
